BudgetWatch — Macro Matrix (Phase 1)
======================================

The four indicators to include:
1. Real GDP Growth
2. Nominal GDP
3. CPI Inflation
4. CPI Index

Official MoSPI API URLs
-----------------------

1) REAL GDP GROWTH
------------------
API:
https://api.mospi.gov.in/api/nas/getNASData?base_year=2022-23&series=Current&frequency_code=Annually&indicator_code=5&Format=JSON

Useful output fields:
- year
- constant_price
- revision
- frequency
- quarter
- unit

How to use:
- Use constant_price (GDP at constant prices) to calculate real GDP growth.
- Growth rate = ((current period constant-price GDP / previous comparable period constant-price GDP) - 1) * 100.
- For annual growth, compare financial years.
- For quarterly growth, use frequency_code=Quarterly and select the relevant quarter/year filters.
- The endpoint returns GDP observations; growth percentage may need to be calculated by BudgetWatch.


2) NOMINAL GDP
--------------
API:
https://api.mospi.gov.in/api/nas/getNASData?base_year=2022-23&series=Current&frequency_code=Annually&indicator_code=5&Format=JSON

Useful output fields:
- year
- current_price
- revision
- frequency
- quarter
- unit

How to use:
- Use current_price (GDP at current prices) as nominal GDP.
- The same NAS endpoint is used for Real GDP and Nominal GDP; use the appropriate response field.
- For quarterly values, use frequency_code=Quarterly and relevant quarter/year filters.


3) CPI INFLATION
----------------
API:
https://api.mospi.gov.in/api/cpi/getCPIData?base_year=2024&year=2022%2C2023&month_code=1%2C2%2C3&limit=20

Useful output fields:
- year
- month
- state
- sector
- division
- inflation

Recommended headline filters:
- state: All India
- sector: Combined
- division: CPI (General)

How to use:
- Use inflation for the monthly CPI inflation rate.
- Quarterly and annual averages can be calculated from the selected monthly inflation observations.
- The example URL requests selected months only. For a full time series, request all required months and handle pagination.


4) CPI INDEX
-------------
API:
https://api.mospi.gov.in/api/cpi/getCPIData?base_year=2024&year=2022%2C2023&month_code=1%2C2%2C3&limit=20

Useful output fields:
- year
- month
- state
- sector
- division
- index

Recommended headline filters:
- state: All India
- sector: Combined
- division: CPI (General)

How to use:
- Use index to show the consumer price index level over time.
- Use inflation to show the percentage change in prices.
- The CPI API can provide Rural, Urban, and Combined series through the sector filter.


API PARAMETER NOTES
-------------------
GDP:
- base_year: 2011-12 or 2022-23
- series: for 2011-12, Current or Back; for 2022-23, Current only
- frequency_code: Annually or Quarterly
- indicator_code: 5 for Gross Domestic Product (based on the supplied API URL)
- Format: JSON or CSV
- Other optional filters include quarterly_code, year, approach_code, revision_code,
  account_code, institutional_code, industry_code, subindustry_code, and page.

CPI:
- base_year: 2010, 2012, or 2024
- For base_year 2010 or 2012, level is required: group, subgroup, or item.
- For base_year 2024, the classification hierarchy is division -> group -> class
  -> sub-class -> item.
- Filters include year, month_code, state_code, sector_code, division_code,
  group_code, class_code, sub_class_code, item_code, limit, and page.

Important:
- These are example API request URLs using the parameters supplied for BudgetWatch.
- Numeric values in the example responses may be returned as strings.
- For complete history, select the needed year/month ranges and paginate as required.
- Confirm code mappings and quarterly response details against the live API documentation.
